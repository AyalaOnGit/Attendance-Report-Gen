# ReportGen - אוטומציה של דוחות נוכחות

כלי חכם מבוסס Python לעיבוד דוחות נוכחות סרוקים (PDF), שינוי זמנים אקראי (Variation) וייצוא לדוחות מעוצבים בפורמט PDF ו-Excel.

## 🚀 יכולות
- **OCR וניתוח טקסט:** חילוץ נתונים מתוך דוחות סרוקים (תמיכה בפורמט א' וב').
- **חישוב ימים אוטומטי:** זיהוי היום בשבוע לפי התאריך לדיוק מקסימלי.
- **שינוי זמנים חכם:** הוספת "סטייה" אקראית לשעות הכניסה והיציאה למראה אותנטי.
- **ייצוא כפול:** יצירת קובץ Excel לעבודה עם נתונים ו-PDF מעוצב להגשה.

## 🛠 התקנה

1. יש לוודא שמותקן במחשב [wkhtmltopdf](https://wkhtmltopdf.org/downloads.html).
2. התקנת הספריות הנדרשות:
   ```bash
   pip install -r requirements.txt
   ```
## 📂 מבנה התיקיות
- `src/`: קבצי המקור של התוכנה.
- `templates/`: תבניות HTML לעיצוב ה-PDF.
- `data/inputs/`: כאן שמים את קבצי ה-PDF המקוריים.
- `data/outputs/`: כאן ייווצרו הדוחות החדשים.

## 💻 שימוש
פשוט שמים את הקבצים בתיקיית ה-`inputs` ומריצים:

```bash
python src/main.py
```
